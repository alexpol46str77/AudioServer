# 🎛️ Audiophile CUE Splitter & Music Hub (FastAPI + Streamlit + PostgreSQL)

Асинхронный клиент-серверный веб-сервис для аудиофилов, позволяющий управлять локальной музыкальной коллекцией, автоматически нарезать lossless-аудиофайлы (FLAC) на отдельные треки по CUE-листам с одновременным сжатием в MP3-превью, вести историю прослушиваний и оценивать любимые композиции.

## 🏗️ Архитектура и стек технологий
Проект спроектирован по классической клиент-серверной архитектуре:
- **Frontend (Клиентская часть):** Python + **Streamlit** (Windows). Оснащен многопоточной фоновой обработкой аудио (модуль `threading`), интерактивным прогресс-баром и системой динамического выбора рабочих директорий.
- **Backend (Серверная часть):** **FastAPI** + **Uvicorn** (Запуск как локально, так и в контейнерах **Podman/Docker** на Linux Mint).
- **База данных:** **PostgreSQL 16** (Развернута в изолированном контейнере).
- **Безопасность:** Профессиональное хэширование паролей с солью через **pure-bcrypt** (защита от радужных таблиц и brute-force).
- **Оптимизация базы:** Внедрен **Пул соединений (Connection Pool)** на базе драйвера `asyncpg` с механизмом внедрения зависимостей **FastAPI Depends** (Внедрение зависимостей).
- **Скрытие секретов:** Конфигурация БД вынесена в изолированное окружение **`.env`** (добавлено в `.gitignore`).

## 🛠️ Функциональные возможности
1. **🔐 Защищенный личный кабинет:** Стабильная веб-форма авторизации и регистрации новых пользователей с валидацией данных.
2. **📁 Динамические каталоги:** Возможность указать любой произвольный путь к музыкальной папке на диске прямо из веб-интерфейса.
3. **📀 Фоновый аудио-процессинг:** Нарезка FLAC-образа на WAV-треки с помощью `soundfile` и генерация MP3-превью через утилиту `FFmpeg` в фоновом потоке (интерфейс не зависает во время обработки).
4. **📊 Умный SQL-апсерт (Upsert):** Учет рейтинга и счетчика прослушиваний треков в реальном времени с защитой от дублирования строк на уровне СУБД (`ON CONFLICT` логика).

## 🚀 Как запустить проект

### 1. Подготовка Базы Данных (Linux Mint / Podman)
Запустите контейнер СУБД с пробросом портов и постоянным хранилищем:

podman run -d --name audiophile_postgres -p 5432:5432 -v audioserver_pgdata:/var/lib/postgresql/data mirror.gcr.io/library/postgres:16-alpine


### 2. Настройка окружения на Windows
Создайте в корне проекта файл `.env`:

```text
DB_USER=your_database_user
DB_PASS=your_secure_password
DB_NAME=your_database_name
DB_HOST=192.168.0.106
DB_PORT=5432
```


### 3. Запуск Backend-сервера (FastAPI)
```powershell
pip install fastapi asyncpg bcrypt python-dotenv uvicorn
python -m uvicorn main:app --reload --port 8000
```

### 4. Запуск Frontend-клиента (Streamlit)
```powershell
pip install streamlit soundfile requests
streamlit run app.py
```
